# Canadian Privacy & Tag Governance Checklist

**Regulatory Standard:** PIPEDA and Bill C-27 (CPPA) Standards  
**Maintained by:** [TAVARDT Canada](https://ag.tavardt.com/ca/)  

---

## Technical Audit Points

* **Meaningful Consent:** Enforce 'denied' default state for all non-essential telemetry and advertising storage.
* **Bill C-27 Alignment:** Restrict cross-context behavioral tracking without explicit opt-in.
* **Data Minimization:** Redact query parameters and personal identifiers from tracking beacons.
* **GTM Exception Triggers:** Block third-party marketing tags dynamically when consent is withheld.
